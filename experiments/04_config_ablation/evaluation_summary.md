# 評価サマリー — Experiment 04

## レイヤーごとの主な役割

| Layer | 主に効いた対象 | 効果 |
|---|---|---|
| Scene Card | Scene構造・Scene Question | 高い |
| Character Context | 人物の振る舞い | 高い |
| Addressing Rules | 呼称 | 非常に高い |
| Style Guide | 表記・短文傾向 | 中〜高 |
| Style Guide | 時制・説明抑制・暗示性 | 低い |

## 最も明確だった分離

```text
Scene Card
→ What happens

Character Context
→ How characters behave

Addressing Rules
→ Who calls whom what

Style Guide
→ How prose is formatted
```

この分離は、Configを一枚の巨大なプロンプトとして扱うのではなく、役割別レイヤーへ分ける設計の妥当性を支持します。

## 設定外補完

A0〜A3のすべてで完全には消えませんでした。

特に学校生活のような一般的文脈では、

- 授業
- テスト
- 宿題
- 体育
- スマートフォン

など、モデルが「自然そうな内容」を自律的に補う傾向があります。

Character Context等を追加しても、人物行動の自由度は減る一方、イベントや世界情報の空白は残るため、補完そのものは継続します。

## 抽象心理表現

全条件を通して、

- 違和感
- 何か
- 胸
- 心の奥
- 予感

などを直接利用する傾向が残りました。

Style Guideで行動・表情・感覚を優先しても、これらは十分に置き換わりませんでした。

## 制約の守られやすさ

### 守られやすい

- 固定呼称
- 括弧形式
- 一人称指定
- 短文傾向

### 中程度

- キャラクター性
- 距離感
- MacroなScene構造

### 守られにくい

- 現在形の維持
- 説明を減らす
- 感情を行動だけで示す
- 伏線の意味を具体化しない
- Scene Questionを文章中で直接言わない

## 結論

本実験で最も重要だったのは、

> LLMは局所的・明示的・機械的な制約ほど守りやすく、抽象的・全体的・長距離の制約ほど守りにくい

という傾向です。

これは今後のナラティブ生成システム設計において、

> 高次の品質制御をすべて一回の生成プロンプトへ押し込まない

という設計方針につながります。
