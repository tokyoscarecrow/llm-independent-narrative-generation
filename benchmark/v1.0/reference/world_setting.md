# 世界設定参照資料 — World Setting Reference

> Benchmark用の参照資料です。人間が本文生成以前に設計していた作品背景を示すためのものであり、**このファイル全体が自動的にLLM入力へ含まれるわけではありません**。

## 作品概要

- タイトル: かんなぎダイアリー / Kannabi Memorandum
- ジャンル: 現代ファンタジー／シニカル社会派コメディ
- 中核テーマ: 自分の可能性を拡げ、人生を切り開くのに大事なものは勇気だ
- 基本構造: 三幕構成（導入／対立／解放）

## 世界設定

舞台は現代日本。

約10万人に1人が「魔法者」と呼ばれる特異体質を持つ。

正式名称は「特種能力者」。その存在は歴史的に隠蔽され、国家中枢では最高機密として扱われている。

厚生労働省地方局には魔法者を把握・監視する担当部署があり、重大な違反者には社会的隔離を伴う強制措置が取られる。

## 魔法

魔法は精神エネルギーを物質へ作用させる能力であり、感情変動と強く連動する。

### パッシブ能力 / Passive Ability

- 周囲の他者感知
- 接触時の思考読取
- 自然発生であり、原則として禁止対象ではない

### アクティブ能力 / Active Ability

- 固体・液体・気体のいずれか一系統を操作
- プラズマ操作は最も危険な能力として扱われる

## 基本的な禁止事項

- 他者に影響を与える魔法の使用は禁止
- 魔法の存在や、自身が魔法者であることを他者へ告げてはならない
- 魔法の使用を他者に目撃・察知されてはならない
- 他の魔法者の存在を公言してはならない
- 日常生活の利便に限る自己使用は黙認される場合がある

## このBenchmarkでの扱い

EP01_SC02は、基本的には学校生活を描く日常シーンです。

そのため、上記の世界設定の多くは**作品背景として存在しているだけで、BenchmarkのScene Cardには直接含まれていません**。

この区別は意図的なものです。

Benchmarkでは、

> 実際に与えられたシーン仕様だけを使って、LLMがどこまで設計意図を守れるか

を評価します。

したがって、人間側では既知の設定であっても、実験入力に含まれていなければ、LLMが当然知っているものとして扱いません。
