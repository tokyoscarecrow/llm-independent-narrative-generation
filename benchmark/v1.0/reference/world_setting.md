# World Setting Reference

> Benchmark reference material. This file describes human-authored story context and is **not** automatically part of the LLM input.

## Project

- Title: かんなぎダイアリー / Kannabi Memorandum
- Genre: 現代ファンタジー／シニカル社会派コメディ
- Core theme: 自分の可能性を拡げ、人生を切り開くのに大事なものは勇気だ
- Narrative structure: 三幕構成（導入／対立／解放）

## World

現代日本。

約10万人に1人が「魔法者」と呼ばれる特異体質を持つ。

正式名称は「特種能力者」。存在は歴史的に隠蔽され、国家中枢では最高機密として扱われている。

厚生労働省地方局には魔法者を把握・監視する担当部署があり、違反者には社会的隔離を伴う強制措置が取られる。

## Magic

魔法は精神エネルギーを物質へ作用させる能力で、感情変動と強く連動する。

### Passive Ability

- 周囲の他者感知
- 接触時の思考読取
- 自然発生であり、原則として禁止対象ではない

### Active Ability

- 固体・液体・気体のいずれか一系統を操作
- プラズマ操作は最も危険な能力として扱われる

## Core Restrictions

- 他者に影響を与える魔法の使用は禁止
- 魔法の存在や、自身が魔法者であることを他者へ告げてはならない
- 魔法の使用を他者に目撃・察知されてはならない
- 他の魔法者の存在を公言してはならない
- 日常生活の利便に限る自己使用は黙認される場合がある

## Note for This Benchmark

EP01_SC02 itself is primarily a school-life scene. Most of the world-setting information above is **background design** and is not included in the benchmark Scene Card.

This distinction is intentional: the benchmark evaluates whether the LLM follows the supplied scene specification without importing story information that was not actually provided as input.
